## About

A small lifestyle blog built with React, TypeScript and React Router. 
It includes a Home page, Posts, Post Detail pages, Contact, a custom 404 page, 
and a protected Dashboard page. The blog features dynamic rendering of posts, 
local state for likes using React Context, and 3 unit tests written with Vitest.
